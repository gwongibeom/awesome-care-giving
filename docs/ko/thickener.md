# 연하보조제
## 연하보조제란
연하보조제(aka 점도증진제)란 음식물이나 물을 입에서 위장으로 보내는 삼킴 과정에 문제가 생긴 상태인 연하장애 환자를 위해 음료 혹은 국 등에 섞어 점도를 증가 시키는 용품입니다.

## 구매처
비스코, 이지밀 토로미 등의 제품이 존재하며 **특수의료식품이지만 대다수의 약국에선 판매하지 않습니다.**

필요한 경우 인터넷 쇼핑몰을 통해 구매할 수 있고, 급하게 필요한 경우 근처에 있는 대학병원에 위치해 있는 의료기상사에서 구매할 수 있습니다.

직접 구매를 통해 보유여부가 확인 된 의료기상사
- 건국의료기
- 한양의료기
